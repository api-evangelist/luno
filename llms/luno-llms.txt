# Luno

> Luno is a cryptocurrency exchange operating across Africa, Europe and Asia,
> offering wallets, buying/selling and trading of Bitcoin, Ethereum and other
> assets. The Luno API is a REST API (plus a WebSocket market-data stream) for
> market data, account management, trading, transfers and withdrawals.

## API

- [Luno API reference](https://www.luno.com/developers/api): Full REST API documentation
- [Developer portal](https://www.luno.com/api): API overview and key management
- Base URL: https://api.luno.com — legacy API under /api/1/, Exchange API under /api/exchange/{1,2,3}/
- Auth: HTTP Basic with an API Key ID (username) and API Key Secret (password); public market-data endpoints need no auth
- Streaming: wss://ws.luno.com/api/1/stream/{pair} (real-time order book + trades)

## Operations (selected, REST)

- GET /api/1/tickers, GET /api/1/ticker — price tickers
- GET /api/1/orderbook, GET /api/1/orderbook_top — order book
- GET /api/1/trades — recent trades
- GET /api/exchange/1/markets, GET /api/exchange/1/candles — markets & candles
- GET /api/1/balance — wallet balances
- GET /api/1/accounts/{id}/transactions, /pending — account ledger
- POST /api/1/postorder, /api/1/marketorder, /api/1/stoporder — trading
- GET /api/1/listorders, GET /api/1/orders/{id}, GET /api/1/listtrades — orders
- POST /api/1/send, POST /api/1/withdrawals — transfers & withdrawals
